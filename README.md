# Atlas Releases

Installers and the update feed for **Atlas**, the site inspection app on OS MasterMap.

- Download the latest macOS installer from [Releases](https://github.com/matv99/Atlas-Releases/releases/latest), open the DMG and drag Atlas to Applications.
- Installed copies keep themselves up to date from [`update-manifest.json`](update-manifest.json) (Help › Check for Updates in Atlas).

Builds are ad-hoc signed, not notarised: the first time, right-click Atlas in Applications and choose Open.
